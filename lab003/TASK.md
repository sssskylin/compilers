
### Задача А. Как пройти в библиотеку?

**Легенда:** Вы работаете в команде, которая поддерживает высоконагруженный сервис, преимущественно написанный на языке C++ (математическое ядро написано на чистом C для производительности и портируемости, а бизнес-логика — на C++). Ранее вся математическая логика была вшита в основной бинарник (статическая линковка), что раздувало его размер и мешало обновлять алгоритмы без перекомпиляции всего сервиса. Ваш тимлид поручил вам выделить математическое ядро в отдельную библиотеку. 

**Требования к окружению:** Linux (или WSL / Docker / Lima / ВМ на ваш выбор) с установленными `gcc`/`g++` и `binutils`.
**Формат сдачи:** Текстовый файл с ответами на вопросы и выводом команд.

## Исходные файлы

Создайте три файла в одной директории.

**`vector_math.h`**
```c
#ifndef VECTOR_MATH_H
#define VECTOR_MATH_H

#ifdef __cplusplus
extern "C" {
#endif

extern const char* get_lib_version(void);
int dot_product(const int* a, const int* b, int n);

#ifdef __cplusplus
}
#endif

#endif
```

**`vector_math.c`** 
```c
#include "vector_math.h"

static const char* LIB_VERSION = "v2.4.1-release";

const char* get_lib_version(void) {
    return LIB_VERSION;
}

int dot_product(const int* a, const int* b, int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i] * b[i];
    }
    return sum;
}
```

**`main.cpp`**
```cpp
#include <cstdio>
#include <iostream>
#include "vector_math.h"

int main() {
    int v1[] = {1, 2, 3};
    int v2[] = {4, 5, 6};

    std::cout << "Library version: " << get_lib_version() << std::endl;
    std::cout << "Dot product result: " << dot_product(v1, v2, 3) << std::endl;

    return 0;
}
```
